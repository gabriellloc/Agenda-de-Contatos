# 📒 Sistema de Agenda de Contatos – Python
Este projeto é um sistema de agenda de contatos desenvolvido em Python, com funcionalidades completas para cadastrar, listar, modificar e remover contatos de forma simples e intuitiva.

A aplicação roda no terminal e permite gerenciar facilmente informações como nome, telefone e status de favorito, além de organizar e exibir os contatos em ordem alfabética e com formatação personalizada (Favoritos separados dos normais).

## 🔧 Funcionalidades
- Adicionar contatos com nome, telefone e favoritado
- Editar informações de um contato existente
- Remover contatos por ID
- Marcar ou desmarcar contatos como favoritos
- Listar todos os contatos
- Ordenação alfabética automática
- Tratamento de erros com <code>try/except</code>

## 🧠 Tecnologias e conceitos utilizados
- Python 3
- Estruturas de dados (listas e dicionários)
- try/except para validação e tratamento de erros
- enumerate() para controle de índice
- Manipulação de strings (split, join, capitalize, slicing etc.)
- Programação orientada a objetos

## ▶️ Como executar


```bash
    python main.py
```

**OBS**: Para utilizar, é necessário instalar o [python](https://www.python.org).
